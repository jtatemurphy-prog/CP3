# Final design

`../design.json` is the submission: design **Q10**, accepted by `brick check` on all four courses.

| Course | Plain (s) | Offset 1 mm (s) | Commands 50 ms late (s) |
|---|---|---|---|
| Steps | 2.45 | 2.43 | 2.45 |
| Rope | 2.77 | 3.29 | 2.91 |
| Ramp | 3.46 | 3.43 | 3.37 |
| Bridge | 1.78 | 1.78 | 1.78 |
| **Total** | **10.46** | | |

Q10 is the Z4c hardware (U12 with free-spinning helper wheels and the centred deck as chassis) with a soft-start program:
`[{"t":0,"motor":"all","level":6},{"t":0.7,"motor":"all","level":7}]`.
It is regenerated by `agent_gen/gN.py` + `agent_gen/z4c.py`.

**Ev1** (2026-11-22) = Q10 + `"start_gap_mm": 0` (front of the vehicle on the start line; the goal is judged on the
rear, so Q10's default gaps were wasted distance). Same hardware and program. All 12 acceptance runs pass:

| Course | Plain (s) | Offset 1 mm (s) | Commands 50 ms late (s) |
|---|---|---|---|
| Steps | 2.36 | 2.42 | 2.36 |
| Rope | 2.67 | 2.55 | 2.74 |
| Ramp | 3.37 | 3.33 | 3.38 |
| Bridge | 1.73 | 1.73 | 1.73 |
| **Total** | **10.13** | | |

(Linux VM; Q10 measured 10.62 s on the same machine. See DESIGN_LOG.md for the rope robustness tests.)

**Ev2** (2026-11-22 evening) = Ev1 + a fully wound pullback (spring) motor on each rear wheel axle, XL motors at
level 5 for 0.7 s then 7. All 12 acceptance runs pass: plain steps 1.59, rope 2.20, ramp 1.85, bridge 1.47 =
**7.11 s** (offset 1.60 / 2.70 / 1.84 / 1.47; late 1.60 / 2.21 / 1.86 / 1.48). See DESIGN_LOG.md.

**Ev3** (latest) = Ev2 + helper wheels moved outward + rear rope wheel driven from both sides, XL level 5 for
0.5 s then 7. All 12 acceptance runs pass: plain steps 1.69, rope 2.15, ramp 1.73, bridge 1.43 = **7.00 s**; its rope
passed 14/14 offset/delay perturbations on two machines (Ev2's rope can stall: 3.8 s on the Mac).

Files here:
- `Q10.json`: the final design (identical to `../design.json`).
- `Ev1.json`: Q10 with `start_gap_mm: 0` (10.13 s).
- `Ev2.json`: Ev1 + two pullback motors (7.11 s here, 8.7 s on the Mac: slow rope).
- `Ev3.json`: the fastest robust design (7.00 s). To submit a design, copy it over `../design.json`.
- `U12.json`: the first design accepted on all four courses (14.41 s).
- `Z4c.json`: Q10's hardware at full power, which fails the rope offset run.
- `DESIGN_LOG.md`: the full experiment log.
